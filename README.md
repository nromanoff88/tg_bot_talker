# Bot Talker 2 — Живой участник Telegram-групп с гибридной памятью и веб-админкой

Сервис автономного Telegram-бота для групповых чатов, который наблюдает за общением, изучает каждого участника изолированно внутри конкретной группы, выжидает окончание мысли собеседника (`Debounce`), ставит эмодзи-реакции, вступает в обсуждения по своему желанию и умеет сам инициировать диалоги в тишине.

Архитектурная документация: [`ARCHITECTURE.md`](./ARCHITECTURE.md).

---

## Быстрый старт в Docker Compose

### 1. Создайте бота и отключите Privacy Mode
1. Напишите `@BotFather` в Telegram → `/newbot` и скопируйте токен.
2. **Обязательно отключите Privacy Mode**: отправьте `@BotFather` команду `/setprivacy` → выберите бота → нажмите **`Disable`**.
   *(Если бот уже был добавлен в группу до отключения Privacy Mode, удалите его из группы и добавьте заново, чтобы Telegram начал передавать ему обычные сообщения).*

### 2. Настройте `.env`
Скопируйте шаблон переменных окружения:

```bash
cp .env.example .env
```

Заполните в `.env` минимум:
- `TELEGRAM_BOT_TOKEN` — токен от `@BotFather`
- `ADMIN_USERNAME` и `ADMIN_PASSWORD` — логин/пароль для входа в веб-админку
- `JWT_SECRET_KEY` — любая длинная случайная строка
- `LLM_API_KEY` — ключ от OpenRouter / OpenAI / совместимого API *(его также можно ввести или поменять позже прямо в веб-админке без перезапуска контейнеров)*

### 3. Запустите все сервисы

```bash
docker compose up -d --build
```

Откройте веб-админку в браузере:
- **URL**: `http://localhost:8080`

## Состав контейнеров

| Сервис | Описание |
| :--- | :--- |
| `postgres` | `pgvector/pgvector:pg16` — бессрочная история сообщений, изолированные карточки людей, атомарные факты и векторные эпизоды (`HNSW`) |
| `redis` | `redis:7-alpine` — таймеры склейки серий сообщений (`debounce`), очереди `ARQ` и `Pub/Sub` шина событий |
| `backend-api` | `FastAPI` — REST API + live `SSE` поток для веб-админки |
| `bot-gateway` | `aiogram 3` — Long Polling, `Debounce`-координатор, принятие решений, имитация печати и отправка реакций/ответов |
| `memory-worker` | `ARQ` — фоновое пакетное изучение участников, векторизация эпизодов и планировщик спонтанной инициативы |
| `admin-ui` | `Nginx + React + TypeScript + Tailwind` — единая точка входа на порту `8080` |

## Основные возможности админки

- **Изолированные досье участников**: просмотр и редактирование прозвища в чате, характера, отношения бота, скрытых заметок админа и списка атомарных фактов. Любую ручную правку защищает механизм **`Admin Lock / Pin`** — фоновый ИИ никогда не перезапишет закреплённые вами данные.
- **Контекст группы и `pgvector`**: редактирование саммари группы, локальных мемов и правил, просмотр векторных эпизодов и проверка семантического поиска прямо из интерфейса.
- **Тонкая настройка поведения в каждой группе**: своя Персона/легенда на каждую группу, ползунок общительности (`Chattiness`), `Debounce` в секундах, кулдауны, лимит сообщений в час, список разрешённых эмодзи, частота собственной инициативы и «Тихие часы» по часовому поясу чата.
- **Живой чат и Мысли бота (`Decision Log`)**: обновление ленты в реальном времени (`SSE`), объяснение каждого решения классификатора («почему промолчал / почему ответил»), список использованных фактов/эпизодов, расход токенов и ручная отправка сообщений от лица бота.
- **Импорт истории Telegram Desktop**: загрузка `result.json` для ретроспективного изучения старого чата и его участников.
